# OpenStreetMap implementation notes

Перевірено 2026-09-03 за офіційними джерелами.

- Дані OpenStreetMap ліцензовані Open Data Commons Open Database License (ODbL); похідні дані мають зберігати сумісні умови ліцензування.
- На карті потрібно постійно й читабельно показувати атрибуцію: `© OpenStreetMap contributors` із посиланням на https://www.openstreetmap.org/copyright.
- Для стандартних raster tiles офіційна політика вказує URL `https://tile.openstreetmap.org/{z}/{x}/{y}.png`.
- Не можна ховати атрибуцію під UI, вимикати її перемикачем або розміщувати за межами доступного екрану.
- Для нативного застосунку слід задати стабільний ідентифікаційний User-Agent із назвою Territory Riders; вебклієнт має зберігати коректний Referer.
- Потрібно поважати кешування тайлів, не надсилати no-cache за замовчуванням і кешувати щонайменше сім днів, якщо клієнт не може коректно читати серверні заголовки.
- Стандартні сервери OSM не мають SLA; для зростання аудиторії варто передбачити можливість перейти на окремого tile-провайдера або власно розгорнуті/керовані тайли, зберігаючи атрибуцію.
